# ESP_Battery
Controling BLE JKBMS, GTN1200, Emerson R48 and getting power from HEEP request to regulate 

This is the raw code of my ESP32S3 controling my ESS.
The proposed Yaml code was only tested on an ESP32S3 and need Home Assistant to trigger battery charge or discharge. 

It is based on :

https://github.com/leodesigner/esphome-emerson-vertiv-r48
https://github.com/syssi/esphome-jbd-bms
https://github.com/syssi/esphome-jk-bms
https://github.com/syssi/esphome-soyosource-gtn-virtual-meter
https://github.com/SeByDocKy/myESPhome 

Some of the sources has been forked and slightly modified to adapt on my integration. This code might be modified without warning to adapt to my future needs
